# ZeroTrustWallet - Biometric Verification Engine (Backend)

## 📖 Description
The ZeroTrustWallet Backend is a Node.js and Serverless Postgres API that powers a continuous, multi-modal biometric authentication system. Rather than relying on rigid passwords or heavy machine learning models, this backend evaluates human behavioral telemetry in real-time using lightweight statistical models. It processes keystroke dynamics, swipe gestures, and device micro-tremors to calculate a continuous trust score. Furthermore, it acts as a cryptographic verifier, authenticating Salted Hash Zero-Knowledge (ZK) tokens generated by the Android edge device to approve financial transactions without ever exposing raw biometric data.

## ⚙️ Core Architecture
* **Keystroke Engine:** Uses Statistical Mean Deviation to calculate the Absolute Percentage Difference (APD) of live typing rhythms against a database baseline.
* **Gesture Engine:** Uses an Exponential Moving Average (EMA) algorithm to track swipe velocity and trajectory deviations.
* **IMU Engine:** Uses 3D Kinematic Variance to measure physical hand micro-tremors via accelerometer and gyroscope vectors.
* **ZK Verification:** Reconstructs and verifies temporal-salted hex tokens for transaction authorization.

## 🚀 How to Run

**Prerequisites:**
* Node.js (v16 or higher)
* A Neon Serverless Postgres database instance

**Setup Steps:**
1. Clone the repository and navigate to the project root:
   ```bash
   git clone [https://github.com/asjsolo/ZeroTrustWallet-Backend.git](https://github.com/asjsolo/ZeroTrustWallet-Backend.git)
   cd ZeroTrustWallet-Backend

2.Install dependencies:
   npm install

3.Create a .env file in the root directory and add your Neon Postgres connection string:
    PORT=3000
    DATABASE_URL=postgresql://<user>:<password>@<neon-hostname>/<dbname>?sslmode=require

4.Start the server:
    npm start
   

## Further Improvements
Redis Caching Pipeline: Implement a Redis caching layer for user baselines to reduce Neon Postgres read operations and further minimize latency during continuous scoring.

Edge Function Migration: Migrate the statistical models to Cloudflare Workers or Vercel Edge Functions to process biometric batches physically closer to the user's mobile device.

Adaptive Tolerances: Introduce contextual variance thresholds (e.g., automatically widening the IMU tolerance if the accelerometer detects the user is running or riding in a vehicle).
